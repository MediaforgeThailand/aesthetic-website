# Aesthetic Website

Landing page สำหรับคลินิกความงาม (Aesthetic Clinic) สร้างด้วย [Next.js](https://nextjs.org) + [Tailwind CSS](https://tailwindcss.com)

## เริ่มต้นพัฒนา

```bash
npm install
npm run dev
```

เปิด [http://localhost:3000](http://localhost:3000) เพื่อดูผลลัพธ์

แก้ไขหน้าเว็บหลักได้ที่ `app/page.tsx`

## Deploy

โปรเจกต์นี้ deploy บน [Vercel](https://vercel.com)
